# BLE DPV 曲线绘图器

## 数据格式

网页按固定 9 字节、小端序解析：

| 偏移 | 长度 | 内容 |
|---:|---:|---|
| 0 | 1 | 帧头 `0xA5` |
| 1 | 2 | `point`，`uint16` |
| 3 | 4 | `current`，`int32`，单位 nA |
| 7 | 1 | 数据区 1～6 字节累加和的低 8 位 |
| 8 | 1 | 帧尾 `0x5A` |

示例：`A5 44 00 72 06 00 00 BC 5A`，解析为 `point=68`、`current=1650 nA`。

## 使用方法

1. 将本目录中的 `index.html` 部署到任意 HTTPS 静态网站。
2. 用安卓 Chrome 打开部署地址，开启手机蓝牙。
3. 保持默认 UUID，或填写模块实际的服务 UUID、通知特征 UUID。
4. 点击“连接 BLE”，从系统列表选择模块。
5. 设置 X、Y 轴范围，数据通过通知到达后自动校验并绘图。

Web Bluetooth 不允许普通 `file://` 页面访问蓝牙，因此直接双击本地 HTML 只能查看界面，不能连接设备。

## 默认 UUID

- 服务：`0000ffe0-0000-1000-8000-00805f9b34fb`
- 通知特征：`0000ffe1-0000-1000-8000-00805f9b34fb`

## 部署方法

可使用 GitHub Pages、Cloudflare Pages、Netlify 等静态托管服务。只需上传 `index.html`，无需服务器程序或数据库。
